Chatsistant connects to Claude through a first-party native MCP connection. Authorized users can work with supported Chatsistant resources conversationally, directly inside Claude, while keeping permission scope and approved write actions under their control.

**Status: Pending Anthropic directory listing** · Closed deployment · API key authorization

### What you can do

- **Read**: ask Claude to read chatbot details, AI agents, knowledge sources and source tags, and to review conversations and messages.
- **Write** (with separate permission): Claude can prepare changes — add an FAQ, rename a source, create or update a source tag, or update chatbot or agent settings. Every change opens a Chatsistant review page that shows the account, chatbot and exact before-and-after fields. Nothing is applied until you approve it there.

The Chatsistant connector provides 19 tools for working with your chatbots, agents, sources, conversations, leads, and bookings: 11 read tools and 8 protected-write tools. Release 0.2.1.

Claude web and desktop are the primary connection experiences. Other supported surfaces follow Anthropic's current platform and plan requirements.

### Before you start

- A Chatsistant account with API access (the API add-on or a plan that includes it).
- A Chatsistant API key, created under Account → API-Keys.
- The UUID of each chatbot you want to connect, shown on its card in your dashboard.

### Connect Chatsistant in Claude

1. Once Chatsistant is listed, open Customize → Connectors in Claude, find Chatsistant in the directory, and choose Connect.
2. Claude opens the secure Chatsistant connection page at claude-mcp.chatsistant.com. Enter an account label, paste your API key into the key field, and enter each chatbot UUID. Never paste API keys into a chat.
3. Choose Read Only (the default) or Read + Write.

**After approving access, return to Claude to complete your connection.**

- If you started connecting from the Claude desktop app, select "Open desktop app" if prompted.
- If you started connecting from your browser, return to Claude in your browser.

Confirm that Chatsistant shows as Connected.

4. Select **Connect selected chatbots**, then return to Claude as described above and confirm Chatsistant shows as Connected.
5. In a chat, turn on Chatsistant from + → Connectors and ask: "List my connected Chatsistant chatbots."

### Make a change

Ask for a specific change, for example "Add an FAQ to my support chatbot."

Claude prepares the change and gives you a review link. Open the link, check the details, then approve or cancel. Return to Claude to apply it.

Requests expire after ten minutes. Read Only connections can't prepare or apply changes.

### Change or remove access

To change which chatbots are connected, choose Reconnect in Claude and select the complete set you want.

Disconnect in Claude to remove the connector from your session. For server-side retirement of that connection, contact Chatsistant support from your account email. If you need to disable the API key itself immediately, revoke it in Chatsistant. That also affects other integrations using the same key.

### Not included in this release

Deleting anything, sending messages, uploading files, importing URLs, and Claude Code.

### Privacy and support

Your API key is entered only on Chatsistant's connection page. It is stored encrypted and is never shared with Claude.
